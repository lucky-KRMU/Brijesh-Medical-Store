## ◈ 01 — Project Overview

**Brijesh Medical Store** is a medical-store project focused on bringing a modern digital experience to healthcare and pharmacy-related services.

The goal is to combine a clean user interface, convenient product discovery, and a user-friendly shopping experience in one place.

> *Technology should make healthcare simpler, faster, and more accessible.*

